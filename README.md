# 海外債利差試算

每個交易日自動抓玉山銀行的海外債券參考報價，算出每檔債的到期殖利率，
再讓你輸入自己的信用貸款條件，試算「借台幣買外幣債」這筆操作到底划不划算。
網站掛在 GitHub Pages，資料靠 GitHub Actions 更新，整套零成本。

## 這個工具在回答什麼

不是「哪檔債的殖利率最高」，而是：

- 你的**實質資金成本**是多少（貸款利率加上開辦費攤提後的真實年化）
- 扣掉資金成本、換匯成本、稅之後，**淨利差**還剩多少
- 整段期間你得**自己墊多少現金**（債息是半年配，貸款是每月還，中間有缺口）
- 外幣要貶多少，這筆操作才會**由賺轉賠**

最後一項通常是決定性的。多數看起來誘人的利差，撐不過 10% 的匯率反向。

## 部署

1. 建 repo，把檔案推上去。
2. **Settings → Actions → General → Workflow permissions** 選 **Read and write permissions**。
3. **Settings → Pages → Source** 選 **GitHub Actions**（不是 Deploy from a branch）。
4. 到 **Actions** 手動跑一次 `更新報價並部署網站`。
5. 網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`。

之後每個工作日台北時間 09:30 自動更新，改網站程式碼 push 上去也會立刻重新部署。

```bash
pip install -r requirements.txt
```

打開 <http://localhost:8000>。

## 計算方法與假設

**殖利率**。玉山的頁面只給價格，沒給殖利率，所以 YTM 是自己解的：
從到期日往回推配息日、加上應計利息算出含息價，再用二分法解折現率。
日計基礎 ACT/365。零息債單獨處理，永續債沒有到期日所以只算當期殖利率。

**結算日**用的是「申購參考報價的報價日」，不是今天。有些債的報價停在兩年前，
表格裡會標出來，那種報價算出的殖利率沒有參考價值。

**模擬**假設貸款金額全額投入（自備款為零），每月還款、債息按配息頻率進帳、
期末若債券已到期就拿回面額，若還沒到期就依當時殖利率反推價格賣出並扣掉買賣價差。
換匯成本在買進與賣出各收一半。

**內部報酬率**用掃描法而不是直接二分：配息月現金流為正、其他月為負，
NPV 曲線會有多個零點，只取區間兩端會漏掉有意義的那個解。

## 這個工具沒有處理的事

- 報價不是成交價，玉山明說以交易確認單為準
- 信用風險完全沒有被計價，RR5 的高收益債違約就是本金歸零
- 匯率用單一情境，沒有做機率分布
- 通路服務費（年化最高 0.5%）由發行機構付給銀行，已隱含在報價裡，沒有另外拆出來
- 最低稅負制只做了簡化的單一稅率，金額大請自己算

**這不是投資建議。** 作者不是理財顧問，所有數字都可能有錯。
用借來的錢投資會同時放大獲利與虧損，而且貸款照繳。決定前請自己驗算並諮詢專業人士。
